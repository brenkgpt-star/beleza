## 🚀 Como Postar no Render (render.com)

O projeto já está **100% configurado** para o Render! Você pode publicar de duas formas:

### Opção 1: Via Static Site no Render (Recomendado — Gratuito)
1. Crie um repositório no seu GitHub e suba este projeto (`git init`, `git add .`, `git commit -m "site"`, `git push`).
2. No painel do [Render](https://dashboard.render.com/):
   - Clique em **New +** e selecione **Static Site**.
   - Conecte o repositório do GitHub.
   - Preencha os campos:
     - **Name**: `site-estetica` (ou o nome que preferir)
     - **Branch**: `main` (ou a branch que você usou)
     - **Build Command**: `npm run build`
     - **Publish Directory**: `dist`
3. Clique em **Create Static Site**.
4. Pronto! O Render vai rodar o build e fornecer uma URL pública (ex: `https://site-estetica.onrender.com`).

---

### Opção 2: Via Blueprint Automático (`render.yaml`)
Como o arquivo [`render.yaml`](./render.yaml) já foi incluído na raiz do projeto:
1. No painel do Render, clique em **New +** > **Blueprint**.
2. Conecte seu repositório.
3. O Render vai ler o `render.yaml` automaticamente e configurar tudo sozinho com 1 clique!
